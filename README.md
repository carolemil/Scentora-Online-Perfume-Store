# Scentora – Online Perfume Store

Scentora is a front-end online perfume shopping website developed using HTML, CSS, and JavaScript.

## Features
- Browse men's, women's, and unisex perfumes.
- Search and filter perfumes.
- View special offers.
- Add and remove products from the shopping cart.
- User registration and login interfaces.
- Admin product management dashboard.
- JavaScript form validation.

## Technologies
- HTML5
- CSS3
- JavaScript
- GitHub
